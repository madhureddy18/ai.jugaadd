The channel run by nobody.

MoneyPrinterTurbo is a free, open-source app. You type one topic, and it writes the script, finds a stock clip for every line, adds a voice, subtitles and music, and renders a finished Short. It can make several versions at once and even post them. You pick good topics.

What you need

  1. A computer (Windows, Mac or Linux). A GPU is not needed.
  2. A free Pexels API key for the stock clips: sign up at pexels.com/api and copy your key. (Pixabay works too, also free.)
  3. An AI to write the scripts, pick one:
    • Your Claude Pro/Max plan: install Claude Code, log in once, then choose Claude Code as the provider. No API key needed.
    • A free local model with Ollama.
    • Or any API key you already have (OpenAI, Gemini, DeepSeek…).
  4. Voice: nothing to set up. The default voice (Edge TTS) is free and needs no key.

Step 1 · Install (pick one)

EASIEST · WINDOWS

Option A: one-click package

  1. Open the latest release and download the .7z file under Assets (not "Source code").
  2. Extract it to a simple path with no spaces, like C:\mpt.
  3. Double-click update.bat first, then start.bat. The app opens in your browser (use Chrome or Edge if it's blank).
ANY COMPUTER · PYTHON 3.11+

Option B: two commands

  1. Make a virtual environment (Mac/Linux shown):
    python3 -m venv .venv
source .venv/bin/activate

    Windows PowerShell: python -m venv .venv then .venv\Scripts\Activate.ps1

  2. Install and start:
    python -m pip install mpt
mpt webui

    The official package is mpt (by the author). The one called "MoneyPrinterTurbo" on PyPI is from someone else.

DOCKER

Option C: Docker

  1. Clone it and copy the config:
    git clone https://github.com/harry0703/MoneyPrinterTurbo.git
cd MoneyPrinterTurbo
cp config.example.toml config.toml
  2. Start it, then open http://127.0.0.1:8501:
    docker compose -f docker-compose.release.yml up

Step 2 · Settings (once)

  1. Click Basic Settings at the top of the web app to expand it.
  2. LLM provider: choose Claude Code (uses your Claude plan), Ollama (free, local) or paste the key for the one you use.
  3. Pexels API key: paste the key you copied.
  4. Voice: pick a free Edge TTS voice and press Voice Sample to hear it.

Step 3 · Make a Short

  1. Video Subject: type one line, for example:
    5 facts about black holes
  2. Click Generate Script & Keywords with AI. Read it and fix anything you don't like.
  3. Video Aspect Ratio: 9:16 for Shorts and Reels. Video Source: Pexels.
  4. Pick a voice, turn on Enable Subtitles and pick Background Music.
  5. Set Videos per Run to 3–5 to get several versions, then click Generate video.
  6. Watch them all and keep the best one.

Step 4 · Posting (optional)

  1. Upload it yourself in YouTube Studio and schedule the week. Takes 10 seconds per video.
  2. Or let the app post for you: it connects to Upload-Post (a separate service with its own account and API key) and can publish to YouTube Shorts, Instagram and TikTok. Turn it on in the settings and pick your platforms.

Tips

Topics are the real job. One good, specific topic a day beats ten random ones.
Don't post junk on repeat. YouTube doesn't pay channels for mass-produced, repetitive videos. Check every script, mix your own ideas in and keep quality high.
Check facts. AI scripts can be wrong. Read the script before you render.
Stock clips are free, but check the license on Pexels/Pixabay if you plan to monetize.
