Overview

Each reel is made entirely in code, with no camera and no editing app: an AI (Claude) writes the script and the 3D scenes, a free voice tool makes the voices, and you review and approve. A 36-second reel takes about 3 hours end to end, half of it the render.

reel pipeline · 8 steps

Steps 1–3 decide what the reel says and looks like, 4–6 produce the video, and 7–8 get it posted and measure it.

Step 1: Idea and script

Every reel starts as a written script, and nothing is built until I say "build".

  1. Pick the idea. One relatable moment or one useful thing (a prompt, a GitHub repo, a trick). Reels that give something away for free get saved and shared most.
  2. Write the hook first. The first 2 seconds must say what's coming. Example: "Hey Claude… how many animation styles can you do?" A hook that hides the point loses people.
  3. Write the lines. Maddie asks or reacts; Claude answers short and dry. 12–18 lines, about 30–40 seconds.
  4. Mark the emotions. Tags like [sigh], [laughter], [surprise-oh], [surprise-wa], [question-en] go on the lines that need them.
  5. Mark the caption keywords. Words in *stars* turn yellow in the subtitles.
  6. End with a one-word CTA. "Comment CLAUDE", "Comment PROMPT". Never a sentence for viewers to type.
  7. Review and approve. I read the script, ask for changes, then say "build".

Step 2: Characters and look

The two characters and the room are built once in code and reused in every reel.

  • Maddie: a 3D cartoon boy made from shapes in three.js (a JavaScript 3D library). Rules: human-looking body with shoulders, arms and legs connected; small lip movement while talking; no blush dots.
  • The AI sidekick: a round hover-bot with headphones and a glowing face. It blinks, winks, tilts and hovers.
  • The set: a purple living room with a couch, popcorn bowl, curtains, fairy lights and a city window. Each reel can move to a new location when the story needs it.
  • Acting: each line gets poses (look at Claude, chin on hand, lean in, smile) and camera shots (close-up, two-shot, push-in).
  • Screen rules: full 9:16 frame with no black bars, captions high on screen with yellow keywords, no page handle or name tags on the video.

Step 3: Animation style selection

The same 3D scene can be redrawn in different styles, so a new look costs code, not a new set of models. The style is switched per shot by a shader (a small program that recolors every pixel after the 3D render).

How I choose: pick the style that matches the line's emotion, keep one style per beat, and cut on the line where the style changes. A reel can stay in one style or switch on every line, like a "how many styles can you do?" reel.

Step 4: Voices

Voices come from OmniVoice Studio, a free, open-source voice app (an ElevenLabs alternative) that runs on your own computer with no API key. It can design a new voice from a description and clone it from a short clip. The cast used here: Maddie = American teen, the AI sidekick = young British.

  1. Install OmniVoice Studio from its GitHub page and open it.
  2. Design each voice once. In Voice Design, set gender, age, accent and pitch ("male, teenager, moderate pitch, American accent"), generate one sample line and save it.
  3. Clone from that saved sample every time. Generate every line from the same saved clip in Voice Clone, so the characters sound identical in every reel.
  4. One file per script line. Name them in order (01.wav, 02.wav…). Add emotion where the script marks it: a sigh, a laugh, surprise, a question tone.
  5. Clean up. Trim the silence at both ends of each clip. Add a style effect where it fits: crunchy 8-bit sound for pixel art, echo for neon, a tiny high voice for the diorama.
  6. Listen and fix. Regenerate any line that sounds rushed or flat, slower or reworded. 18 lines take about 10–15 minutes.

Step 5: Building the scene in code

Each reel is one scene file: a lines file (the script) plus a body file (everything you see and hear). Claude writes both.

  1. Timeline from the voices. The real length of each voice clip sets when every line starts, so cuts and effects are tied to the words, not to guessed seconds.
  2. Shots. Each beat gets a camera shot; a cut lands on the line that changes the style or the mood.
  3. Acting. Poses and expressions are set per line: Maddie looks at Claude, leans in, smiles; Claude winks or tilts.
  4. Motion graphics (the HUD). Titles, style badges (1–7), counters (7 → ∞), code on screen, the "PICK YOURS" wall and the comment card are drawn on top of the 3D.
  5. Captions. Each line becomes a subtitle placed high on screen, keyword in yellow.
  6. Sound. Pops, whooshes, coins and bass hits on the cuts, background music that dips under key lines and goes quiet for the big turn.

Step 6: Previews and the final render

The video is drawn frame by frame in a hidden Chrome browser, then joined with the voices, music and sound into one MP4.

  1. Still previews. A few frames at the busiest moments are drawn and checked first: captions, badges, nothing overlapping.
  2. Line preview. One frame per line, with voices, to check timing and that every graphic shows when it should (for example, ∞ appears before the code reveal).
  3. Full render. Every frame at 1080 × 1920, 30 fps. A 36-second reel = about 1,090 frames at about 5 seconds each, so about 1.5 hours.
  4. Check the result. A contact sheet (one frame every 2.3 seconds) confirms every section before you watch the MP4.

Important: changing only the voices still needs a full render, because the new clip lengths shift every cut, caption and mouth movement.

Step 7: Posting

Post the MP4 straight from the Instagram app as a Reel.

  1. Watch it once on your phone. Check sound levels and that the captions are readable at phone size.
  2. Cover. Pick the frame with the hook title so the grid shows what the reel is about.
  3. Caption. First line repeats the hook, then a short list of what's inside, then the one-word CTA ("Comment CLAUDE and I'll send you all of them").
  4. Hashtags. 3–5 specific ones (#animationstyles, #3danimation, #claudeai), not 30 generic ones.
  5. Time. Post when your audience is online; midday and 7–9 PM work well in India.
  6. Deliver the freebie. Send what you promised to everyone who comments the word.

Step 8: Checking results

Open the reel's Insights after 24 hours and compare it with your usual numbers. These four matter most:

MetricWhat it tells you
SavesPeople want to come back to it: the strongest push signal
SharesPeople sent it to friends: reach beyond your followers
Avg watch timeWhether the hook and pacing held them (aim for over half the reel)
CommentsWhether the CTA worked

One example: a reel with a free prompt giveaway got 13,000 views, 554 saves and 201 shares, against about 1,500 views on a normal reel, with average watch time more than doubled.
