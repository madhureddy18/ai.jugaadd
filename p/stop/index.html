The 3 settings

1Instagram's own daily limit

Instagram reminds you when you hit your limit. Set it lower than you think: 30–45 minutes.

Profile → ☰ menu → Time management → Daily limit

Also turn on Sleep mode in the same place so notifications go quiet at night.

2A real app timer (harder to ignore)

Your phone greys out the app when time's up. This is the one that actually stops the scroll.

Android: Settings → Digital Wellbeing → Dashboard → Instagram → App timer
iPhone: Settings → Screen Time → App Limits → Add Limit → Instagram

3Grayscale at night

A black-and-white feed is boring, and boring is the point. Reels lose their pull instantly.

Android: Digital Wellbeing → Bedtime mode → turn on Grayscale and set your hours
iPhone: Settings → Accessibility → Display & Text Size → Color Filters → Grayscale (add it to Accessibility Shortcut for a triple-click toggle)

Menu names can differ a little by phone brand. Search the setting name in your phone's Settings search bar if you can't find it.
