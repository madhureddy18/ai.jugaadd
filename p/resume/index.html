AI JUGAAD · EP 1

300 applications, 0 calls?
Use this prompt.

Paste it into Claude (or any AI chat) with the job post and your resume. 2 minutes per job.

Here's a job description and my resume.

1) List the important skills and keywords in the job post that are missing from my resume.
2) Rewrite my resume bullet points to match this job, using numbers from my real work (time saved, users, accuracy, marks, project size).
3) Do NOT add any skill or experience I don't have. If something is missing, tell me instead of inventing it.
4) Write a 2-line summary for the top of my resume for this role.
5) Give me the final resume text, ready to copy.

JOB POST:
[paste the job description here]

MY RESUME:
[paste your resume here]

How to use it

  1. Copy the job description from Naukri / LinkedIn / the company site.
  2. Copy your resume text.
  3. Paste both into the prompt and send.
  4. Check every line is true, then save it as a new PDF for that job.
Only true things. If the AI suggests a skill you don't have, learn it or leave it out. Interviewers ask about every line.
