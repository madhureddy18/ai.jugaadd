The free /effects skill for Claude Code. Drop in your video, type one command, get a whole new edit.

Open the GitHub repo →

Install (1 line)

1
Paste this in your terminal (or the terminal inside Claude Code), then restart Claude Code: 
git clone https://github.com/Vibha-Ramprakash/claude-video-effects ~/.claude/skills/effects

Windows (PowerShell): use $HOME\.claude\skills\effects instead. Or just paste this into Claude Code and let it install for you:

Install the skill from github.com/Vibha-Ramprakash/claude-video-effects into ~/.claude/skills/effects

Use it

2
Open Claude Code and drag your video into the chat. Vertical phone videos with you in frame work best.
3
Type the effect you want: 
/effects spotlight when I say "watch"
/effects orbit from 3 to 6 seconds
/effects backdrop-word with the word BORING behind me
/effects reject-stamp on "no"
4
Claude checks a few frames, keeps your face clear, and renders yourvideo_effects.mp4 next to the original. Your audio stays the same. Stack several in one go.

First run sets itself up (about 2 minutes; it installs ffmpeg + Python if missing). The effects are free, but they run inside Claude Code, which needs a Claude plan. These are starter versions: no sounds or captions are added, so finish in CapCut. Always watch before you post.
