career-ops is a free, open-source AI job search agent that runs inside Claude. It finds jobs, scores each one against your CV, writes a tailored resume and cover letter, and fills the form. You press Submit.

What you need

  1. A Claude account with Claude Code: a Claude Pro or Max plan works. (It also runs on other AI CLIs and free/local models, see the repo's "Running on a budget" guide.)
  2. A computer (Windows, Mac or Linux). It doesn't run on a phone.
  3. Your CV as a PDF or text, and an idea of the roles you want.
  4. Only for Option C: Node.js 22.13+ and git.

Step 1 · Install (pick one)

EASIEST · no terminal

Option A: Claude desktop app

  1. Open the Claude desktop app → Customize → Plugins.
  2. Click Add → Add marketplace and paste:
    career-ops-hq/career-ops
  3. Open Discover, find career-ops and click Add.
  4. Open the Code tab and start a new session. The first start takes a few seconds while it installs.
CLAUDE CODE IN THE TERMINAL

Option B: two commands

  1. Open Claude Code and type:
    /plugin marketplace add career-ops-hq/career-ops
    /plugin install career-ops@career-ops
  2. Close it and start a new session.
FULL WORKSPACE

Option C: its own folder

  1. Install Node.js 22.13+ and git, then run:
    npx @santifer/career-ops init
  2. Go into the folder and open Claude Code:
    cd career-ops
claude

In this folder the command is /career-ops. With the plugin (A or B) it's /career-ops:career-ops.

Step 2 · First run: tell it about you

  1. Type /career-ops:career-ops (or /career-ops in Option C). On a fresh setup it starts a chat to set you up. Nothing to edit by hand.
  2. Paste your CV when it asks.
  3. Tell it what you want and what you refuse. For example:
    I graduated in 2026 (B.Tech). I want fresher roles: data analyst, backend developer, cloud. Hyderabad, Bengaluru or remote. No unpaid internships, no sales roles.
  4. Add the companies you care about. It also reads career pages built on Darwinbox and Keka, which many Indian companies use:
    Add these companies to portals.yml: [company 1], [company 2], [company 3]

Step 3 · Use it every day

Paste a job linkThe full pipeline: checks the job is still live, scores it 1–5 against your CV, writes a report, makes a tailored CV (PDF) and adds it to your tracker.

interview-prepPrep notes for a specific company's interview.

Type the word after the command, e.g. /career-ops:career-ops scan. Plain English works too: "run the career-ops scan".

Tips

Read every CV before you send it. It rewrites your CV for each job but must not invent things. Check it anyway.
Trust the score. It tells you not to apply below 4.0/5. Fewer, better applications beat 60 copies of the same resume.
On a Claude Pro/Max plan? If an ANTHROPIC_API_KEY is set on your computer, Claude Code bills the API instead of your plan. Remove it and log in with /login.
The first runs are rough. Talk to it like a recruiter in their first week: what you liked, what you didn't. It learns.
