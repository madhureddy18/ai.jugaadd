13 free Claude skills that run your Instagram

Open source (MIT) by Jake Schincariol. No Instagram password, no API key, no signup.

Open the GitHub repo →

Install (2 minutes)

1
Open Claude Code (terminal, or the Code tab in the Claude desktop app) and run: 
/plugin marketplace add Jakeschincariol/instagram-agent-skill
/plugin install instagram-agent
2
Or the easy way: paste this into Claude Code and let it install everything: 
https://github.com/Jakeschincariol/instagram-agent-skill

Install this skill, then confirm /ig-reel works.
3
Set your voice once. Copy templates/voice.md to ~/.claude/instagram/voice.md and fill it in, or send Claude three of your reels and ask it to write that file for you. Every skill reads it, so spend ~10 minutes here.
4
Type /ig-reel with your idea. That's it.

The 13 commands

/ig-viralFinds what's working in your niche, ranked against each account's normal views
/ig-reelOne idea → scored hooks, script, on-screen text, timed beats
/ig-humanRemoves AI-sounding words from any draft
/ig-planYour week: what to post, format, timing, accounts to engage
/ig-dmKeyword DMs, first messages, collab pitches, follow-ups
/ig-captionWrites and checks captions, previewed like the feed
/ig-carouselSwipe posts: cover, slide copy, 1080×1350 files
/ig-storyDaily story sequence and what each sticker is for
/ig-profileScores your profile out of 100, then rewrites it
/ig-repurposeOne video or podcast → a week of reels and carousels
/ig-auditReviews your past posts by outlier multiple
/ig-commentComments on others' posts, matched to what each post says
/ig-replySorts the replies under your post and drafts answers

Good to know

The skills are free, but they run inside Claude Code, which needs a Claude plan. They write things for you to copy; they never log in to Instagram or post for you. /ig-viral works from links or screenshots you give it. Read the repo files before installing any community skill.
